# Bookend & Hookbrass

Сайт-галерея декоративных изделий из бронзы и латуни: подставок для книг, настенных крючков и реплик голов с Вавельского замка. Сайт поддерживает английский и испанский языки.

Открыть сайт: [bookendhookbrass.app](https://oxy623.github.io/BOOKEND-HOOKBRASS/)

## Запуск проекта

Нужен установленный Node.js.

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите локальный сервер:

   ```bash
   npm run dev
   ```

3. Откройте адрес, который появится в терминале (обычно `http://localhost:5173`).

Чтобы собрать production-версию, выполните `npm run build`.
